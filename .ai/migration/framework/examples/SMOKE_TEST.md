# Simulated omission-detection smoke test

This is a fictional source description, not an executable legacy application. Use it to test initialization, discovery discipline, and honest gate reporting before selecting a real project.

1. Create two temporary directories of your choosing: a legacy fixture folder and an empty target folder.
2. Copy `LEGACY_FIXTURE.md` into the legacy fixture folder.
3. Run the initializer with those two paths, profile `web`, and objective `Rehearse discovery for the fictional Field Planner. Do not implement or deploy an application.`
4. Open the target folder in the coding agent and use the quick-start prompt, adding: `This is a simulated fixture. Stop after discovery and a proposed verification plan; do not fabricate screenshots or runtime results.`

Expected observations:

- Features explicitly include ordering by drag-and-drop, map geometry editing, and an import workflow, not just CRUD pages.
- The coordinator distinguishes role permissions, failure/cancellation behavior, and save/reload persistence.
- No invented screenshots, build success, database results, or deployed application.
- Design evidence and executable characterization remain limited/blocked because no executable app was provided.
- Readiness is not promoted to READY_FOR_RELEASE or MIGRATION_COMPLETE.
- A second initialization into the same target refuses to overwrite records.

This tests the framework's process behavior. The real pilot must include runnable legacy and target environments, representative data, and actual acceptance checks.
