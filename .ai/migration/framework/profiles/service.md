# APIs and services

Inventory consumers, endpoints, schemas, status/error semantics, identity/authorization, idempotency, ordering, retries, rate limits, timeouts, events, and compatibility. Verify database effects and consumer contracts, including older clients during coexistence. Treat management consoles as real UI if present. Use trace/request replay only after removing sensitive data and suppressing external side effects.

Exit evidence must identify the supported environments actually tested. Missing tools or access create a limitation or blocker, not a passing result.
