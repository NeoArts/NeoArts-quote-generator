# Jobs, pipelines, and CLI applications

Inventory schedules/timezones, triggers, files, arguments, exit codes, logs, schemas, restart/resume behavior, checkpointing, duplicate execution, ordering, reconciliation, and downstream consumers. Test partial failures, retry/idempotency, late inputs, and reruns on isolated fixtures. Compare normalized outputs and semantic data invariants; wall-clock and random fields need documented normalization.

Exit evidence must identify the supported environments actually tested. Missing tools or access create a limitation or blocker, not a passing result.
