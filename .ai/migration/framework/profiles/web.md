# Browser applications

Inventory routes including deep links, menus, roles, dialogs, keyboard/mouse/touch interactions, responsive layouts, and browser storage. Verify refresh/back navigation and persistence. Use controlled screenshot environments and browser end-to-end checks. Include accessible labels, focus, keyboard operation, downloads/uploads, drag-and-drop, and canvas/map editors where present. Network mocks cannot prove live integrations.

Exit evidence must identify the supported environments actually tested. Missing tools or access create a limitation or blocker, not a passing result.
