# Desktop applications

Capture windows, menus, shortcuts, dialogs, native file selectors, filesystem effects, clipboard, multi-window behavior, installer/update flows, and platform permissions. Use a platform-appropriate automation adapter or documented manual evidence. Browser-only tests do not prove native functionality. Test supported OS/display scaling configurations and upgrade/uninstall behavior in an isolated environment.

Exit evidence must identify the supported environments actually tested. Missing tools or access create a limitation or blocker, not a passing result.
