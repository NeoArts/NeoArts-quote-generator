# All applications

Inventory every input/output surface, actors, permissions, persistent data, integrations, jobs, and operational procedures. Select a reproducible execution adapter. Record platform and tool limitations. Mark UI stages N/A only after confirming there is no user-facing interface; replace visual checks with the relevant interface contract. Do not impose a web stack or assume an available browser.

Exit evidence must identify the supported environments actually tested. Missing tools or access create a limitation or blocker, not a passing result.
