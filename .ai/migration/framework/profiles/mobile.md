# Mobile applications

Capture navigation, gestures, permissions, offline/sync behavior, notifications, deep links, device storage, orientation, and accessibility. Use representative supported devices or emulators and record differences from physical devices. Verify lifecycle/background/restore behavior and app upgrade data compatibility. Store submission and production push notifications are separate authorized actions.

Exit evidence must identify the supported environments actually tested. Missing tools or access create a limitation or blocker, not a passing result.
